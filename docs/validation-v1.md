# V1 实测记录

日期：2026-10-17；本机真实模型与本地 HTTP API 联调。这里的结果来自保存的模型响应与游戏轨迹，不是测试夹具或演示数据。

## 真实链路

- 玩家：`http://127.0.0.1:18090/v1/systemone`，服务返回 `startlux-decision-27b-autothink`。
- 教练：用户配置的 `https://api.startluxai.com/v1/chat/completions`，请求与返回模型均为 `glm-5.3`。
- 每次玩家请求：`think_mode=never`、`return_details=true`；全部已执行动作的原始响应均为 `thought.used=false`、`thought.tokens=0`。
- GEPA：真实 `gepa.optimize`，安装包 0.1.4，固定 commit `f1cfdee2856e9dc4b5b4dc5cc2e391d0aa20d819`。
- 棋盘 8×8、单局最多 120 步、3 个训练种子、3 个选优种子、4 对发布种子、每次 1 轮反思。

共 **31 个完整游戏回合、959 个动作**：2 局正式游玩、12 局训练评测、9 局选优评测、8 局发布配对评测。每一步都与 StartLux 返回动作一致；用固定引擎重放记录的动作后，所有前后棋盘、得分和结束状态完全匹配。

玩家 HTTP 请求延迟：均值 **81.15 ms**，P95 **91.374 ms**。这是本次串行实验的端到端请求样本，不是并发容量测试，也不代表持续性能保证。

## 控制、错误和检查

- 在第二轮通过 HTTP API 请求暂停，间隔 0.6 秒的两次快照仍为同一回合第 0 步、棋盘完全一致；继续后正常完成游玩、优化和发布。证据：`data/pause-check.json`。
- 首次 GLM 初始化曾返回不合 Harness 结构的内容，程序报错且没有开始游戏。随后补充 JSON 格式约束、明确输出例子、最多一次结构修复；后续真实初始化和两次反思通过。
- **76 个自动测试、9 个子测试通过**，涵盖游戏规则、全部动作回执、冻结局内版本、暂停和停止、真实 GEPA 调用路径、失败不计零分、训练/验证隔离、重启补偿、原子发布、回滚限制及 HTTP 同源限制。
- 前端 JavaScript 语法检查通过；DOM ID 无重复、无缺失引用。前端只有本地 API 请求，无外部脚本依赖。
- 密钥文件 `.env` 权限为 `0600`，被 `.gitignore` 排除；扫描项目源码、产物和日志，未在 `.env` 外发现该密钥。
- 测试依赖产生一条 Starlette / httpx 的弃用提示，不影响当前测试结果。

浏览器权限门禁拒绝打开本地页面，未使用其他浏览器或自动化方式绕过。因此**视觉布局、鼠标点击和浏览器回放交互未做实际验收**；已验证的是后台真实实验、API 控制、前端语法和接口字段。
