# 四个新增游戏：规则、优化与验收

日期：2026-10-17。参考用户指定的 Decision Arena 项目，在已支持贪吃蛇、中国象棋的基础上接入军棋、五子棋、俄罗斯方块、原创平台跳跃。源代码固定在 commit `4e2bda1d6c9b2545837761e2c7d19e2ce546aa9d`，MIT 声明与逐文件 SHA-256 保留在 vendor 目录；参考项目不作修改。

## 共用链路

四个游戏复用现有 GameAdapter、Decision 运行器、GLM 初始化、真实 GEPA、独立于搜索的发布配对和自动导出/Git 同步。模型等待期间所有游戏暂停。游戏规则进程只做状态变化、完整候选枚举和计分，不执行策略搜索。

每个正式回合完成后均生成局后优化任务；评测回合不会递归优化。优化的是决策指令与策略文本，模型权重、规则、评分、固定对手及发布门槛不变。候选未改善或未通过发布门槛，保留原版。

| 游戏 | 默认预算 | 原生得分 | 固定发布门槛 |
| --- | --- | --- | --- |
| 军棋 | 100 半回合 | 胜100、负0、和50；截断中性50 | 至少4对，均增≥2，逐对不退步 |
| 五子棋 | 9×9、81 半回合 | 胜100、负0、和50；截断中性50 | 至少4对，均增≥2，逐对不退步 |
| 俄罗斯方块 | 80次决策、最多120秒模拟时间 | 仅原生消行points | 至少4对，均增≥100，逐对不退步 |
| 原创平台跳跃 | 60次决策、最多120秒模拟时间 | 最远进度×10取整 + 金币×100 + 通关10000 | 至少6对，均增≥100，逐对不退步 |

本轮军棋、五子棋、方块的训练/选优预算分别为2/2场；平台为3/3场，覆盖全部三关。每个任务1次反思。上述分数、预算、门槛在实际优化前固定，不依据实测表现调整。

## 军棋的信息边界

本版是“环境预置合法布阵后的对局策略”任务：种子生成合法布阵，双方在环境初始化时锁定准备，随后每一步走棋由 Decision 选择。不宣称实现模型自主布阵。

- 完整真实棋盘和种子留在规则进程。每个 Decision 请求只含当前方 `observe/view`，不提供对手暗子身份或种子。
- GLM 只获得候选方行动前可见的状态与其动作，过滤对手轮次和行动后切换到对手的观察，防止教练拼接双方视角。不能只删除种子却仍发送对手私有棋盘。
- 网页状态、回放、事件和已发布评测包过滤私有种子；棋盘仅使用双方共同已知的 `public_view`，不显示完整合法动作集合或原始模型响应。
- 参考引擎终局原本会翻明全部棋子；这里的模型/公共投影在终局也保持暗子边界。
- 完整多视角审计证据仍留本机忽略的 `data/`，不提交 Git，不发送给教练；公开回放是脱敏投影。

军棋不同种子确实改变初始布阵；奇偶交换候选席位。五子棋不同种子只交换黑白，都是空棋盘重复试验，不能称为新开局泛化。

## 街机游戏的暂停语义

模型选择完整原生按键目录中的一个按钮组合与100/300/1000ms时长，机械执行对应6/18/60个60Hz物理tick；模型等待不推进tick。动作结束按引擎规则松键，下一次同键会产生新按下边沿。no-op松键并自然推进6tick。

方块保留重力、锁定延迟、SRS、7-bag、hold和五块可见预览，不提供随机状态或额外未来方块，不用自动落点规划。硬降只沿模型已选横向位置和朝向落下。存活时长不加分。

平台跳跃保留原项目三张原创关卡，`seed % 3 + 1` 选关。每组训练/选优覆盖三关，6对发布试验每关两对；不同编号可能重复同一地图。没有自动跳坑、自动避敌或原版马里奥 ROM。

## 产物与运行

全部版本在本机 `data/versions/<version>.json`，原始轨迹在 `data/episodes/` 和 `data/traces/`。只有通过发布验收的版本写入 `harnesses/<game>/<version>/` 五文件包，并在本机开启的自动同步配置下提交到 GitHub。

无需改共用引擎即可运行新增游戏，API 使用 `game_id=army|gomoku|tetris|platformer`。五子棋棋盘参数为 `gomoku_size=9|15`，其余游戏不会接收这个专用字段。Node规则桥已打包；源码重建命令见各 vendor 的 `SOURCE.json`。

浏览器访问曾被工具权限拒绝；本轮仍不绕过该限制。网页新增渲染器及表单只进行静态、纯函数和API校验，实际游戏和优化由后端真实模型运行。
