# Evidence-driven changes

- Fix missing or ambiguous visual context before expanding strategy prose.
- Distinguish an unsuitable action catalog from an incorrect model choice.
- Preserve legitimate abstentions when none of the offered skills applies.
- Use generic scene and target predicates. Never identify an evaluation case.
- Keep observed game facts separate from predicted skill outcomes.
- Deleting all options is an invalid evaluation, never a successful abstention.
- A skill return is execution evidence, not proof of commission or reward state.
